# 모션 수급 가이드 — 참조 영상급 자연스러움 만들기

목표: "선생님, 잠깐 시간 내줄 수 있어" 계열 쇼츠 같은 **전문가 손키 수준의 캐릭터 연기**.
그 자연스러움의 본체는 코드가 아니라 **모션 데이터(VMD)**다. 이 앱은 VMD를
물리·전환 보간·표정 트랙까지 살려서 재생하므로, 좋은 데이터를 구해 넣는 것이
품질의 지름길이다. 경로는 3가지 — A(기성 팩), B(영상→추출), C(자체 생성).

## 공통: 투입 절차 (어느 경로든 동일)

1. **검수**: `node scripts/inspect-vmd.mjs 받은모션.vmd --model src/assets/<모델>/모델.pmx`
   - 본 일치율 80%+ 면 호환 양호. 표정 트랙 유무도 여기서 보인다.
   - 루트 이동 키가 있어도 앱이 자동 제거(제자리 재생)하니 걱정 불필요.
2. **배치**: `src/assets/motions/vmd/<카테고리>/<이름>.vmd`
   - 카테고리: `idle`(대기 연기) / `talk`(말할 때) / `react`(반응) / `emote`(감정 표출)
3. **등록**: `src/assets/motions/vmd/manifest.json`에 이름→파일 매핑 추가
   (이름은 `idle_*`/`talk_*`/`react_*` 규약 — motionManager 어휘와 일치해야 자율 행동이 집어 씀)
4. **빌드+검수**: `npm run build` 후 `node tests/gui/vmd-check.mjs`(3각도 스크린샷),
   문제 있으면 `tests/gui/cloth-measure.mjs`(물리)와 `smoothness-check.mjs`(전환)로 좁힌다.
5. **라이선스**: 재배포 금지 모션은 커밋 금지(.gitignore가 vmd를 기본 차단,
   자체 생성분만 화이트리스트). 폴더에 `LICENSE-<작자>.txt`로 허락 문구를 남긴다.

> 표정 트랙이 든 연기 클립은 재생 중 **앱이 표정 소유권을 클립에 양보**한다
> (2026-07-03 엔진 수정). 즉 모션에 표정까지 들어 있으면 그대로 살아난다.
> 말할 때만 립싱크가 입을 우선 점유한다.

## 경로 A — 기성 고품질 모션 팩 (품질 ★★★, 즉효)

MMD 커뮤니티의 손키 모션. 참조 쇼츠급 연기가 그대로 들어온다.

- **찾는 곳**: 보울롤(bowlroll.net), 니코니코 동영상 모션 배포 태그(`MMDモーション配布あり`),
  YouTube 설명란의 모션 배포 링크. 검색어 예: `待機モーション 配布`(대기),
  `仕草 モーション 配布`(몸짓), `日常 モーション MMD`.
- **고를 때**: ①인물 1명용 ②30fps ③"루프" 명시면 idle에 최적 ④표정 포함이면 최고.
- **라이선스 체크리스트**: 이용규약(readme)에서 — 개인 이용 가/불, 개변 가/불,
  재배포 금지(→커밋 금지), 크레딧 표기 요구. **의심되면 안 쓴다.**
- 다운로드는 사람 손으로(로그인/약관 동의 필요) — 받아서 위 공통 절차로.

## 경로 B — 영상→모션 추출 (품질 ★★☆, 원하는 장면 그대로)

참조 영상의 움직임 자체를 따오고 싶을 때. AI 모캡이 영상에서 전신 모션을 뽑아
**VMD로 직접 내보낸다.**

- **도구**: [QuickMagic](https://www.quickmagic.ai/) — VMD 직수출 지원, 매월 무료
  크레딧. 대안: DeepMotion, Plask, Rokoko Vision (대부분 FBX라 변환 단계 추가됨).
- **입력 영상 요령**: 전신이 다 보이고(발 잘림 X), 인물 1명, 카메라 고정,
  가림(책상 등) 최소. 쇼츠는 상반신만 나오는 경우가 많아 **전신 컷을 골라야** 한다.
- **한계와 보완**: 몸통·팔다리는 충실하지만 손가락·표정은 안 나온다 →
  표정은 A의 표정 클립이나 앱 절차 표정이 담당, 손가락은 handShape 프리셋이 보완.
- 출력 VMD를 공통 절차(검수→배치→등록)로 투입. 본명이 표준 MMD가 아니면
  inspect-vmd 대조에서 바로 드러난다.

## 경로 C — 자체 생성 고도화 (품질 ★★☆, 우리 시그니처)

`scripts/gen-vmd.py`: AI가 설계한 키프레임 JSON을 VMD로 굽는 자체 파이프라인.
현재는 팔·팔꿈치·상체 중심 — 확장 로드맵:

1. 무게 이동(腰/センター 미세 사이클)과 고개-시선 분리 타이밍
2. 손가락 키(30 role 리깅 완료 상태) + 손목 secondary
3. 표정 트랙 동시 생성(모프 키) — 몸짓·표정 동기화
4. 캐릭터 프로필 연동: 성격 수치 → 연기 스타일 변조(이미 페르소나 변조 설계 있음)

**차별점**: A/B는 "남의 연기"지만 C는 **캐릭터 프로필이 자기 연기를 만들어내는
우리 고유 기술**이 된다. 품질 상한은 A보다 낮으니 A/B로 기준을 확보하며 병행.

## 현재 로컬 자산 참고

- Deedee524 idle 팩(재배포 금지, 로컬 전용): `air_scent.vmd` 등 — **표정 트랙
  65종 포함** 확인. 표정 양보 수정으로 이제 표정 연기까지 살아난다.
- 자체 생성분(gen-vmd, 커밋됨): talk 6종·idle 포즈 6종 등.
