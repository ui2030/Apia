# 내 파일과 학습

Apia가 내 PC 어디에 무엇을 남기는지, 그리고 스스로 배우는 기능이 언제 무엇을 하는지 정리했어요.
무엇이 인터넷으로 나가는지는 [개인정보 안내](../../PRIVACY.md)에 자세히 있어요.

모든 파일은 `%APPDATA%\apia` 폴더 안에 있어요.
(여는 법: `Win + R` → `%APPDATA%\apia` 입력 → 확인)

## 1. 개인 설정 폴더 (내 파일)

설정 → **캐릭터 성격** → **내 파일 (개인 설정)** 줄에서 다뤄요. 폴더 위치는 `%APPDATA%\apia\personal`이에요.

- **성격 파일 (`persona.md`)**
  - 이 폴더에 `persona.md`를 넣으면 기본 성격 대신 그 파일로 캐릭터의 말투와 성격을 정해요.
  - 글자 수가 많으면 앞부분(약 8KB)만 읽어요.
  - 앱을 업데이트해도 지워지지 않아요.
  - **폴더 열기**: 탐색기로 이 폴더를 열어요.
  - **기본으로 되돌리기**: 파일을 지우지 않고 이름만 `persona.md.bak-날짜`로 바꿔서 기본 성격으로 돌아가요. 다시 쓰고 싶으면 이름을 `persona.md`로 되돌리면 돼요.
- **목소리 샘플**
  - 폴더 안내문(README)에 `voice` 자리가 적혀 있지만, **지금은 이 자리를 읽는 기능이 없어요.** 목소리는 설정의 **캐릭터 목소리 만들기**로 만들어요([첫 대화](첫%20대화.md) 5번, 설치본에서는 미지원).
  - 만든 목소리는 `%APPDATA%\apia\backend-data\voices`에 저장되고, 설정의 **삭제** 버튼으로 지워요.

## 2. 대화 기록과 장기 기억

- **장기 기억**은 처음부터 켜져 있어요. 주고받은 대화 원문을 내 PC의 `backend-data\apia.db`에 저장하고, 나중 대화에서 관련된 내용을 떠올리는 데 써요.
- 대화 기록이 20개(내 말과 대답을 하나씩 세서, 대략 10번 주고받기) 쌓일 때마다 짧게 요약해 두는데, 이 요약은 지금 쓰는 답변 모델(클라우드 모델이면 인터넷 너머)에게 부탁해요.
- 끄기: 설정 → **정보 활용** → **장기 기억 사용** 토글을 꺼요. 끄면 새로 저장하지 않아요.
- 지우기: 설정 → **정보 활용** → 기억 상태 옆 **기억 모두 지우기**를 눌러요. 확인창에서 한 번 더 물어보고, 저장된 대화 원문과 요약을 모두 지워요. 되돌릴 수 없어요. (학습 노트와 대화 눈치 메모는 따로 남아요.)

## 3. 학습 노트와 야간 학습

Apia에는 "로컬 모델"(내 PC의 AI)을 조금씩 키우는 기능이 있어요. 순서는 이래요.

1. **대화 모으기** — 채팅을 한 번 주고받을 때마다 그 원문을 `courseware\buffers`에 날짜별로 적어 둬요. (**대화를 학습 노트 재료로 모으기** 토글을 끄면 적지 않아요.)
2. **학습 노트 만들기** — 자리를 5분 넘게 비우면, 지난 날짜의 대화를 클라우드 모델(DeepSeek)에게 보내 **이름 같은 개인 정보를 지운 문답 노트**로 바꿔요. 노트가 잘 저장되면 그날 대화 원문은 지워요.
3. **야간 학습** — 학습 노트가 쌓이면, 일주일에 한 번 **클라우드 모델이 로컬 모델을 가르쳐요.** 클라우드 모델이 로컬 모델의 답을 고쳐 주고, 로컬 모델은 그걸로 공부해요.
   - "야간"이라는 이름이지만 시간을 정해 두진 않았어요. 아래 조건이 모두 맞을 때 시작해요.
     - 컴퓨터를 15분 넘게 안 쓰고 있을 때
     - 그래픽 메모리가 8GB 이상 비어 있을 때
     - 지난 학습에서 7일이 지났을 때
     - 새 학습 노트가 10장 이상일 때
   - 최대 2시간까지 하고, 사용자가 돌아오면 바로 멈춰요.
   - 공부한 뒤 시험을 쳐서 **오히려 나빠졌으면 결과를 버리고** 이전 결과를 그대로 써요.

> **설치본에서는:** 로컬 모델과 학습 프로그램이 들어 있지 않아서 3번(야간 학습)은 일어나지 않아요.
> 2번은 DeepSeek 키를 `backend.env`에 직접 적은 경우에만 일어나요(설정 화면에는 DeepSeek 키 칸이 없어요).
> **키가 없으면 1번에서 모은 대화 원문이 지워지지 않고 계속 쌓여요.** 지우는 법은 아래 "되돌리기·끄기"를 보세요.

### 되돌리기·끄기

| 하고 싶은 것 | 방법 |
| --- | --- |
| 학습 노트를 대화에 참고하지 않기 | 설정 → **성장 · 학습 노트** → **학습 노트 참고** 토글 끄기 |
| 학습 결과를 이전 것으로 되돌리기 | 설정 → **성장 · 야간 학습** → **이전 학습 결과로 되돌리기** → 보관본 고르고 **되돌리기** (최근 8개까지 보관) |
| 로컬 모델에게 대답 맡기기 그만두기 | 설정 → **성장 · 야간 학습**에서 맡기기를 끄기. 맡기기는 직접 켤 때만 시작되고, 품질이 떨어지면 알아서 해제돼요. |
| 대화 원문 모으기(1번) 끄기 | 설정 → **성장 · 학습 노트** → **대화를 학습 노트 재료로 모으기** 토글 끄기. 바로 적용되고, 끈 동안에는 야간 학습이 새 노트를 못 만들어요. 이미 모인 원문은 그대로 있어요. |
| 모인 원문 지우기 | 같은 칸의 **모은 원문 지금 지우기** → 확인창에서 **지우기**. 아직 노트로 만들지 않은 원문만 지우고, 학습 노트는 남아요. |
| 야간 학습 끄기 | **지금은 끄는 토글이 없어요.** 학습용 프로그램이 없는 PC(설치본 포함)에서는 저절로 일어나지 않아요. |
| 학습 노트 모두 지우기 | 앱을 끄고 `courseware\cards` 폴더 안 파일을 지워요. |

## 4. 대화 눈치 메모

설정 → **성장 · 대화 눈치 메모 (기록 전용)**에서 봐요. 파일은 `apia-topic-ledger.json`이에요.

- **무엇을 적나요?** 대화마다 **화제 이름**(정해진 26가지 중 하나)과 **숫자들**만 적어요.
  - 숫자: 분류 확신도, 대답까지 걸린 시간, 대답 길이 비율, 화제가 바뀌었는지, 호응 정도
  - **대화 내용(원문)은 적지 않아요.**
- **어디에 쓰나요?** 먼저 말 걸기를 켰을 때 편한 화제를 고르는 데, 그리고 채팅에서 조심할 화제를 먼저 꺼내지 않는 데 써요. 이때도 넘기는 건 화제 이름뿐이에요.
- **화제 분류는 내 PC의 로컬 모델로만 해요.** 그래서 로컬 모델이 없는 설치본에서는 메모가 쌓이지 않아요.
- **얼마나 남나요?** 날짜별 숫자 기록은 90일이 지나면 지워져요. 다만 지우기 전에 화제별 요약 숫자로 합쳐 두고, 그 요약은 계속 남아요.
- **지우기:** 같은 칸의 **초기화** 버튼을 누르면 모두 지워져요.

## 5. 다른 파일들

| 파일·폴더 | 내용 |
| --- | --- |
| `apia-settings.json` | 설정 창에서 고른 값 |
| `apia-world.json` | 방과 가구 배치 |
| `characters\` | 내가 넣은 캐릭터 모델 |
| `backend-data\backend.env` | API 키 (암호화 없이 저장) |
| `logs\main.log` | 앱 동작 기록. 5MB가 넘으면 하나만 남기고 새로 써요. 대화 원문은 적지 않도록 만들었어요. |

전부 지우고 처음 상태로 돌아가려면 앱을 끄고 `%APPDATA%\apia` 폴더를 통째로 지우면 돼요.
