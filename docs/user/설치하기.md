# Apia 설치하기

Apia는 바탕화면에 사는 AI 캐릭터 비서예요. 이 문서는 설치 파일을 받아서 처음 켜기까지를 안내해요.
개인정보가 어디로 가는지는 [개인정보 안내](../../PRIVACY.md)에 따로 정리했어요.

## 1. 필요한 것

| 항목 | 내용 |
| --- | --- |
| 운영체제 | Windows 11 (64비트). 지금까지 Windows 11에서만 확인했어요. Windows 10은 아직 확인하지 않았어요. |
| 디스크 | 설치 파일 약 152MB, 설치 후 약 450MB. 대화 기록·설정이 쌓이면 조금씩 늘어요. |
| 인터넷 | **꼭 필요해요.** 설치본은 내 PC 안에서 돌아가는 AI(로컬 모델)를 담고 있지 않아서, 대답을 인터넷 너머의 AI(클라우드 모델)에게 받아요. 목소리도 인터넷 음성 서비스로 만들어요. |
| 그래픽 카드 | 방과 캐릭터를 3D로 그려요. 보통의 노트북 내장 그래픽에서도 켜지는지는 아직 확인 중이에요. |
| API 키 | 대답을 받으려면 AI 서비스의 키가 하나 필요해요. 다음 문서([첫 대화](첫%20대화.md))에서 받는 법을 안내해요. |

> **로컬 모델과 NVIDIA 그래픽 카드에 대해**
> 내 PC에서 직접 AI를 돌리는 "로컬 모델", 밤사이 스스로 배우는 "야간 학습", 마이크 받아적기, 캐릭터 목소리 만들기는
> NVIDIA 그래픽 카드(그래픽 메모리 8GB 이상)와 별도의 개발 환경이 있어야 해요. **지금 설치본에는 이 기능들이 들어 있지 않아요.**

## 2. 설치하기

1. `Apia-Setup-1.0.0.exe`를 더블클릭해요.
2. 파란색 **"Windows의 PC 보호"** 창이 뜰 수 있어요.
   - 이 설치 파일에는 아직 "코드 서명"(만든 사람을 증명하는 전자 도장)이 없어서 Windows가 경고를 띄우는 거예요.
   - 창 안의 **추가 정보**를 누르면 아래에 **실행** 버튼이 나타나요. **실행**을 눌러요.
3. 설치 위치를 고르는 화면이 나와요. 그대로 두고 **설치**를 눌러도 돼요.
4. 설치가 끝나면 바탕화면과 시작 메뉴에 **Apia** 바로가기가 생겨요.

## 3. 처음 켜기

- 바탕화면의 **Apia**를 더블클릭해요.
- 따로 내려받는 파일은 없어요. 보통 몇십 초 안에 방과 캐릭터가 나타나요.
- 처음에는 보라색 캡슐 모양의 **기본 캐릭터**가 서 있어요. 내 캐릭터를 넣는 법은 [첫 대화](첫%20대화.md)에 있어요.
- 화면 왼쪽 아래에 동그란 버튼 두 개가 있어요.
  - 말풍선 버튼: 채팅 창을 열어요.
  - 톱니바퀴 버튼: 설정 창을 열어요.

## 4. 이럴 땐 이렇게

| 증상 | 이유와 해결 |
| --- | --- |
| 말을 걸면 영어로 `No AI provider is available right now...`라고 대답해요 | 아직 API 키를 넣지 않아서예요. 고장이 아니에요. [첫 대화](첫%20대화.md)의 "API 키 넣기"를 따라 해 주세요. |
| 설정에서 "로컬 모델 (내 PC)"를 골랐는데 대답이 없어요 | 설치본에는 로컬 모델이 없어서, 앱이 자동으로 "자동 (권장)"으로 되돌려요. API 키를 넣어 주세요. |
| 마이크 토글이 눌리지 않아요 / 목소리를 만들었는데 고를 수 없어요 | 설치본에는 마이크 받아적기와 목소리 바꾸기 엔진이 빠져 있어요(1번 표 아래 안내 참고). |
| 캐릭터 창이 안 보여요 | 모니터를 여러 대 쓰면 다른 모니터에 떠 있을 수 있어요. 설정 → 표시 설정 → **표시 모니터**에서 원하는 모니터를 골라요. |

## 5. 지우기

Windows **설정 → 앱 → 설치된 앱 → Apia → 제거**를 누르면 돼요.
앱을 지워도 내 설정·대화 기록 폴더(`%APPDATA%\apia`)는 남아요. 완전히 지우려면 그 폴더도 지워 주세요.
(폴더 여는 법: `Win + R`을 누르고 `%APPDATA%\apia`를 입력한 뒤 확인)
