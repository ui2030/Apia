# 첫 대화

[설치하기](설치하기.md)를 마치고 Apia를 켠 상태에서 시작해요.
화면 왼쪽 아래 **톱니바퀴 버튼**을 누르면 설정 창이 열려요. 바꾼 뒤에는 아래쪽 **저장 및 적용**을 눌러야 반영돼요.

## 1. 캐릭터 고르기·넣기

설정 창 맨 위 **캐릭터 모델** 칸에서 해요.

- 처음엔 **기본 캐릭터**(보라색 캡슐)가 "적용 중"이에요.
- 내 캐릭터를 넣으려면 점선 상자에 파일을 끌어다 놓거나, 상자를 눌러 파일을 골라요.
  - 넣을 수 있는 것: **VRM** 파일, **PMX를 묶은 ZIP**, 또는 모델이 든 **폴더**
  - PMX 모델은 텍스처(그림 파일)까지 함께 묶은 ZIP이나 폴더로 넣는 게 가장 안정적이에요.
- 넣기 전에 아래 칸에 **표시 이름**(화면에 보일 이름), **내가 부를 이름**, **한 줄 설명**을 적어 둘 수 있어요(선택).
- 넣은 캐릭터 파일은 내 PC의 `%APPDATA%\apia\characters` 폴더에 복사돼요. 인터넷으로 올라가지 않아요.

> 캐릭터 모델 파일은 만든 사람의 저작권이 있어요. 배포 조건을 지켜서 개인적으로만 써 주세요.

## 2. 답변 모델 고르기

설정 → **AI 설정** → **답변 모델**에서 골라요. 처음 값은 **자동 (권장)**이에요.

Apia가 쓸 수 있는 AI는 두 갈래예요.

- **로컬 모델**: 내 PC의 그래픽 카드에서 직접 돌아가는 AI예요. 인터넷이 필요 없고 사용료도 없지만, NVIDIA 그래픽 카드(로컬 모델이 그래픽 메모리 약 4.5GB를 차지해요)와 별도의 개발 환경이 필요해요. **지금 설치본에는 들어 있지 않아요.** 골라도 앱이 "자동"으로 되돌려요.
- **클라우드 모델**: 인터넷 너머 회사 서버에서 돌아가는 AI예요. API 키(그 서비스를 쓸 수 있는 열쇠 문자열)가 필요해요.

설치본에서 실제로 고를 수 있는 클라우드 모델은 이래요.

| 메뉴 이름 | 필요한 것 | 비용 | 쓰는 모델(기본값) |
| --- | --- | --- | --- |
| Groq API | Groq 키 (`gsk_`로 시작) | 무료로 키를 받을 수 있어요. 무료 사용량에는 한도가 있어요. | Llama 3.3 70B |
| Claude API | Claude 키 (`sk-ant-`로 시작) | 쓴 만큼 돈이 나가요(Anthropic 요금). | Claude Sonnet 4.6 |
| HuggingFace API | HuggingFace 토큰 (`hf_`로 시작) | HuggingFace 요금 정책을 따라요. | Qwen3-4B |
| Claude Code (구독 로그인) | Claude 유료 구독 + 이 PC에 `claude` 프로그램 설치·로그인 | 구독료 안에서 써요. | 구독 계정의 모델 |

- **자동 (권장)**은 키가 들어 있는 서비스 중에서 Groq → Claude → HuggingFace 순서로 골라요. Claude Code는 자동으로 고르지 않아요. 직접 골라야 해요.
- 처음이라면 **Groq 키 하나만 넣고 "자동"**으로 두는 게 가장 간단해요.
- 속도와 대답의 질은 서비스마다, 날마다 달라서 여기서 단정하지 않을게요. 직접 몇 마디 나눠 보고 골라 주세요.

## 3. API 키 넣기

1. 쓰려는 서비스 웹사이트에서 키를 발급받아요. (예: Groq는 groq.com에 가입한 뒤 "API Keys" 메뉴)
2. 설정 → **AI 설정**에서 해당 칸(**Groq API 키**, **Claude API 키**, **HuggingFace 토큰**)에 붙여 넣어요.
3. **저장 및 적용**을 눌러요. 키가 저장되고 Apia의 대답 엔진이 저절로 다시 켜져요.
- 칸을 비워 두면 기존 키는 그대로예요. 키를 없애려면 칸 옆 **삭제**를 눌러요.
- 키는 내 PC의 `%APPDATA%\apia\backend-data\backend.env` 파일에 **암호화 없이 그대로** 저장돼요. 이 파일을 남에게 보내지 마세요.

## 4. 첫 대화

1. 화면 왼쪽 아래 **말풍선 버튼**을 눌러 채팅 창을 열어요.
2. 하고 싶은 말을 적고 Enter를 눌러요.
3. 캐릭터가 글로 대답하고, 설정의 **목소리로 말하기**가 켜져 있으면 목소리로도 읽어 줘요.
   - 기본 목소리는 Microsoft의 인터넷 음성(한국어 여성 목소리)이에요. 그래서 대답 문장이 Microsoft로 보내져요. 싫으면 **목소리로 말하기**를 끄면 돼요.

키를 안 넣었으면 영어로 `No AI provider is available right now...`라고 대답해요. 3번으로 돌아가 키를 넣어 주세요.

## 5. 목소리 만들기 (캐릭터 목소리)

> **지금 설치본에서는 이 기능을 쓸 수 없어요.** 설정 창에 칸은 보이지만, 목소리를 바꾸는 엔진이 설치본에 없어서 만든 목소리를 고를 수 없어요. 개발 환경에서만 돼요.

개발 환경에서 쓸 때의 원칙이에요.

- 설정 → **캐릭터 목소리 만들기**에 캐릭터 음성 파일(mp3·wav)을 올리면 그 목소리로 말해요.
- **목소리 샘플은 25~30초가 가장 좋아요.**
  - 최소 5초는 있어야 해요.
  - 30초가 넘는 부분은 쓰지 않아요.
  - 길수록 깨끗하지만, 샘플 10초마다 대답이 약 2초 늦어져요.
- **한 호흡으로 이어지는 조용한 대사**가 가장 깨끗해요. 여러 조각을 이어 붙이면 조각 사이 말투 차이가 기계음처럼 들릴 수 있어요.
- 발음은 먼저 인터넷 음성으로 만들고, 목소리 색만 내 PC에서 바꿔요. 그래서 인터넷이 필요해요. 처음 한 번은 음성 모델을 내려받느라 몇 분 걸려요.
- 만든 목소리는 내 PC에만 저장되고, 설정의 **삭제** 버튼으로 지울 수 있어요.
